## Data safety (answers for the form)

- Does the app collect or share user data? **No.**
- Progress and settings stay on the device (SQLite); no account, no analytics, no ads SDK, no network requests.
- "Transfer progress" writes a JSON file only when the user asks and hands it to the system share sheet — the developer never receives it, so it is not "collected" in the Play sense.
- Encryption in transit: not applicable (no data leaves the device through the app).
- Data deletion: "Reset all progress" in Settings or uninstalling the app.
- Advertising ID: **not used** (the `AD_ID` permission is removed from the manifest).
